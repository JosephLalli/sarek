# Implementation Plan: Optimize BCFTOOLS Indexing

This plan details the steps to replace redundant indexing processes with the built-in `-W` argument in `bcftools` commands throughout the Sarek pipeline.

## Phase 1: Identification and Initial Mapping [checkpoint: 2233aad]
*   **Goal:** Map all `bcftools` module usages and their subsequent indexing steps.
*   - [x] Task 1.1: Audit BCFTOOLS Modules: Identify all `bcftools` modules in `modules/nf-core` and `modules/local`.
*   - [x] Task 1.2: Map Workflow Dependencies: Identify every instance in `subworkflows/` and `workflows/` where a `bcftools` command output is immediately piped into an indexing process (e.g., `TABIX`, `BCFTOOLS_INDEX`).
*   - [ ] Task: Conductor - User Manual Verification 'Phase 1: Identification and Initial Mapping' (Protocol in workflow.md)

## Phase 2: Configuration and Module updates (TDD)
*   **Goal:** Update module configurations to enable `-W` and ensure index files are captured in outputs.
*   - [x] Task 2.1: Write Red Tests (Regression): Run existing `nf-test` for a representative module (e.g., `BCFTOOLS_VIEW`) to establish a baseline.
*   - [x] Task 2.2: Update Module Configurations: Add `args = { "${args} -W=tbi" }` (or similar) to `conf/modules/` for the targeted `bcftools` modules.
*   - [x] Task 2.3: Verify Output Channel Capture: Ensure the `main.nf` of each targeted `bcftools` module is correctly capturing the generated index file in its output channel.
*   - [x] Task 2.4: Pass Green Tests: Verify that the `bcftools` module now produces both the VCF/BCF and its index within its own output channel.
*   - [x] Task: Conductor - User Manual Verification 'Phase 2: Configuration and Module updates (TDD)' (Protocol in workflow.md)

## Phase 3: Workflow Refactoring
*   **Goal:** Remove redundant processes and rewire channels.
*   - [x] Task 3.1: Refactor Subworkflows: For each subworkflow mapped in Phase 1:
    *   Remove the `TABIX` or `BCFTOOLS_INDEX` process call.
    *   Update the output of the subworkflow to use the index generated by `bcftools`.
*   - [x] Task 3.2: Refactor Main Workflows: For each workflow:
    *   Remove redundant indexing calls.
    *   Update channel connections to use the direct index output.
*   - [x] Task: Conductor - User Manual Verification 'Phase 3: Workflow Refactoring' (Protocol in workflow.md)

## Phase 4: Final Verification and Cleanup
*   **Goal:** Ensure pipeline integrity and no regressions.
*   - [x] Task 4.1: Execute Regression Suite: Run `nf-test` for all affected subworkflows and workflows.
*   - [x] Task 4.2: Integration Test Run: Execute a full pipeline run using the `test` profile to ensure end-to-end functionality.
*   - [x] Task: Conductor - User Manual Verification 'Phase 4: Final Verification and Cleanup' (Protocol in workflow.md)
